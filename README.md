# ET Samanya Farms

Standalone public website for **ET Samanya Farms** — a 5-acre agroforestry farm. Vegetables, sesame, urad, spinach, and fruit among 1,600+ trees. A little earth. A lot of heart.

This project is not part of Elastic Tree.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — home
- `/farm` — land, journey, pond
- `/harvest` — what we grow
- `/practices` — agroforestry principles
- `/visit` — enquiry form, phone, map

## Stack

Next.js (App Router) + TypeScript + Tailwind CSS.

Set `NEXT_PUBLIC_SITE_URL` in production for canonical metadata and sitemap URLs.
